Seat Classes & Object-Oriented Design

How Inheritance and Dynamic Polymorphism are implemented in this C++ Airline Reservation System.

🏛️ C++ Object-Oriented Programming Architecture

This project is specifically engineered to demonstrate core OOP principles expected in college end-semester evaluation:

1. Abstract Base Class

SeatClass acts as an abstract base class defining pure virtual functions: calculateFare(double), getMealService(), getLoungeAccess(), and getRefundPercentage().

2. Derived Class Inheritance

EconomySeat, BusinessSeat, and FirstClassSeat inherit from SeatClass, overriding each virtual method with specialized business logic and pricing multipliers (1.0x, 2.2x, 3.8x).

3. Dynamic Polymorphism

The Ticket class holds a polymorphic std::shared_ptr<SeatClass>. Calling ticket.cancelTicket() evaluates the correct class-specific refund (70%, 85%, or 100%) at runtime without switch-cases.

4. Encapsulation & Separation

Flight capacity tracking, seat allocation maps, ticket state machines, and socket I/O are completely decoupled across modular C++ header and source units.

C++ Inheritance Hierarchy Snippet C++11 
class SeatClass {
public:
    virtual double calculateFare(double baseFlightPrice) const = 0;
    virtual double getRefundPercentage() const = 0;
    virtual int getBaggageAllowanceKg() const = 0;
};

class BusinessSeat : public SeatClass {
public:
    double calculateFare(double base) const override { return base * 2.2; }
    double getRefundPercentage() const override { return 0.85; } // 85% refund
};
